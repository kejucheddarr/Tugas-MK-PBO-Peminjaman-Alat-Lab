## Penjelasan Studi Kasus
Sistem Manajemen Peminjaman Alat Laboratorium adalah sistem yang digunakan untuk mengelola proses peminjaman dan pengembalian alat laboratorium. Sistem ini mencakup pencatatan data alat, data peminjaman, proses peminjaman, serta pengembalian alat. Sistem ini membantu mengatur proses peminjaman alat laboratorium menjadi lebih terstruktur dan mudah dipantau.
